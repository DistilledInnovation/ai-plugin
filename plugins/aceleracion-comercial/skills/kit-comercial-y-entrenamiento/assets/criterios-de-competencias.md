## 3. Cómo se evalúa

1. Se elige una conversación grabada con autorización o una simulación.
2. Quien evalúa marca las conductas observadas (con una frase de la conversación).
3. Se acuerda el nivel con la persona y se fija un siguiente paso de práctica.
4. Se repite con una conversación distinta antes de subir de nivel.
