## 1. Los 13 indicadores

| ID | Dimensión | KPI | Fórmula o definición | Valor actual | Calidad del dato (contada, estimada, no medido) | Fuente |
|---|---|---|---|---|---|---|
| KPI-01 | Demanda | Leads por canal | Leads únicos del periodo, por fuente | | | |
| KPI-02 | Calidad | % de leads ICP | Leads que cumplen el perfil / leads evaluados × 100 | | | |
| KPI-03 | Activación | Tasa de respuesta | Prospectos que responden / prospectos contactados × 100 | | | |
| KPI-04 | Conversión | Lead a oportunidad | Oportunidades nuevas / leads elegibles del periodo × 100 (definir cohorte) | | | |
| KPI-05 | Conversión | Oportunidad a venta | Oportunidades ganadas / oportunidades cerradas × 100 | | | |
| KPI-06 | Velocidad | Duración del ciclo | Días entre la calificación y el cierre, con una definición consistente | | | |
| KPI-07 | Salud del pipeline | Oportunidades estancadas | Oportunidades sin siguiente paso o sin avance más allá del umbral acordado | | | |
| KPI-08 | Productividad | Actividades útiles por persona | Contactos, reuniones o propuestas según la etapa y la calidad | | | |
| KPI-09 | Valor | Ticket promedio ganado | Valor total ganado / número de negocios ganados | | | |
| KPI-10 | Previsibilidad | Error del forecast | Diferencia entre lo previsto y lo vendido, con método explícito | | | |
| KPI-11 | Eficiencia | Costo por oportunidad | Inversión comercial atribuible / oportunidades generadas | | | |
| KPI-12 | Adopción | Higiene del registro | % de oportunidades activas con responsable, etapa, importe y siguiente paso válidos | | | |
| KPI-13 | Resultados | Ingresos y margen | Ventas y contribución por segmento, canal y periodo | | | |
