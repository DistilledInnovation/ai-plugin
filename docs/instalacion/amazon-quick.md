# Instalar en Amazon Quick

Verificado: 2026-10-25

## Para quien importa la skill

1. Descarga desde **Releases** el zip de la skill y descomprímelo.
2. Abre la aplicación de escritorio de Amazon Quick.
3. Elige **Create > Import from file or folder** y selecciona la carpeta de la skill (el archivo `SKILL.md`).
4. Pruébala con una frase de ejemplo: "Quiero priorizar qué procesos automatizar".
5. Pulsa **Share** y compártela con personas, grupos o con toda la cuenta.

## Para el administrador

El flujo para compartir con toda la organización y controlar quién puede importar skills no pudo confirmarse en la investigación (verificar). Mientras tanto, la persona que importa comparte la skill con los grupos del taller (paso 5).

## Si algo falla

- La importación no reconoce la carpeta: confirma que dentro está `SKILL.md` y no una carpeta extra.
