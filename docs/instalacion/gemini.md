# Instalar en Gemini

Verificado: 2026-10-25

## La forma más corta

Gemini CLI (desarrolladores; necesita [Node.js](https://nodejs.org)):

```
npx skills add DistilledInnovation/ai-plugin
```

Elige Gemini CLI en la lista. Gemini CLI lee `SKILL.md` de forma nativa.

## Gem con copiar y pegar (sin terminal)

Los Gems aceptan instrucciones y unos 10 archivos de conocimiento. La interfaz puede cambiar (verificar).

1. Descarga y descomprime `<metodologia>-copiar-pegar-v*.zip` de **Releases**.
2. En Gemini crea un **Gem** y pega `INSTRUCCIONES.md` en sus instrucciones.
3. Sube como conocimiento los archivos `01-*.md`, `02-*.md`, etc. (el paquete respeta el tope de 10).
4. Guarda y prueba con: "Quiero priorizar qué procesos automatizar".

Se actualiza a mano con cada versión nueva. Gemini Enterprise (servidores MCP) queda fuera del alcance de esta versión.
